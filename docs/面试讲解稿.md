# 面试讲解稿

## 回答要点

参与动力是表达和纪念；AIGC 的作用是把文字意境变成场景；品牌的角色是与心情有关的气泡与白桃饮料；分享自愿；公开大屏和私人创作分开管理。

## 回答方式

先从用户如何参与讲起，点击完成一次生成，再演示扫码领取、分享卡片和上屏申请。最后回到产品方案，说明营销转化、安全以及原型边界。不要从素材库或对照实验开场。

## 完整参考回答稿

我做的是一个叫“此刻有声”的音乐节互动，为一个自拟的白桃气泡水产品服务。用户的参与理由是，把今晚的音乐心情做成一张值得保存和分享的海报，同时拿到一份现场试饮。

页面一打开就是第一道音乐情境题。用户连续回答四个问题后，系统揭晓音乐人格并给出解释；没有直接选人格的入口。然后选视觉风格，留一句话和昵称。点击生成之前不会显示海报。这个演示用三句固定留言代替任意输入，目的是把不同表达对应的结果做完整，而不是假装已经接好了一个生图服务。

这几个输入分工不同。人格影响人物在音乐里的状态，视觉风格决定材质和色彩，留言决定画面到底发生什么。昵称只是署名，不负责决定人物性格。例如去月球、与朋友看日出、把心情交给鼓点，应该对应不同的场景，不能只替换标题。

品牌融入上，我没有把产品一直摆在画面正中间，也没有把它缩成看不清的小角标。我的思路是让气泡和用户想表达的心情发生关系：开罐气泡变成去月球的轨迹，白桃饮料成为朋友在海边碰杯的一部分，或者气泡与舞台声浪汇合。包装和底部品牌区负责识别，画面里的关系负责让用户愿意留住这张海报。

生成后，用户可以直接保存，也可以看二维码和手机领取页，或者把带有海报的卡片分享给朋友。试饮不用先分享，完成海报就能领。这样营销转化落在现场真实体验产品，而不是靠强制转发。

大屏是另一条自愿分支。用户必须明确同意公开昵称和留言，再进入队列。每张展示十二秒，最多排五张，长时间没轮到会过期，运营可以暂停和紧急下屏。个人创作和领取不用限时，因为他们不占用公共屏幕的播放资源。

本地原型验证的是体验是否连贯、不同输入的表达是否成立，以及这些功能是否有明确结果。它没有验证真实分享率和试饮核销率，也没有生产级内容审核。正式上线时，我会补上服务端文字和图像审核、统一队列与券核销，再分别看完成率、保存分享和实际试饮情况。
