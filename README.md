# 此刻有声 · 音乐人格问答原型

**在线体验：[https://chenyiwang325-droid.github.io/shike-music-festival/](https://chenyiwang325-droid.github.io/shike-music-festival/)**

入口为必答的四道音乐情境题；完成后才揭晓人格并继续制作海报。
下载完整提交包后可打开 `离线体验.html`。从仓库克隆时先运行 `python3 build_offline.py` 生成离线文件；也可直接运行 `python3 serve.py`，访问 http://localhost:8765/ 。维护源码位于 dist/。

流程：四题问答并揭晓人格 → 视觉风格 → 预设留言与昵称→ 生成等待 → 独立结果页。初始页面不展示海报；无对照页或重复留言入口。人格只能通过完整四题问答得到；未完成时不能继续，重新创作会清空测评，不能直接切换人格。保存导出 Canvas PNG；扫码弹窗包含手机领取页示例；分享显示海报卡片并支持系统图片分享或下载兜底；试饮券为非真实核销示例；公开上屏需要明确勾选授权。

产品为虚构的此刻白桃气泡水。留言固定三句，场景为事先生成的图片；不调用实时图像 API。有限素材不能代表任意输入均能独立生成。昵称经本地检查后直接排版，不用于推断人格。

## 文件

- dist/index.html：页面与弹窗容器。
- dist/style.css：响应式视觉设计。
- dist/app.js：步骤、示例选择、结果、领取、分享、试饮券与公共队列。
- dist/core.js：人格测评、参数校验、链接编码与队列规则。
- dist/renderer.js：海报统一 Canvas 排版。
- dist/assets/：预生成场景与二维码工具。
- build_offline.py：将脚本、样式、图片嵌入离线体验文件。
- test.cjs：规则验证，执行 `node test.cjs`。

## 演示边界

个人创作无倒计时；公共屏幕每张 12 秒、最多 5 张、等待 10 分钟自动过期，支持撤回、暂停、紧急下屏。队列只演示同一地址来源下的本地浏览器存储，正式环境需服务端统一控制。file:// 本地文件的跨标签页共享受浏览器限制，推荐 localhost 演示公共屏幕。

离线二维码为示例地址；网页内提供领取页示例按钮。localhost 领取链接在同机可还原，手机必须使用可访问的局域网或正式地址。领取链接包含昵称和留言，24 小时失效。未接入真实商品核销、社交平台发布、生产安全审核或用户追踪。

第三方二维码工具许可见 THIRD_PARTY.md。项目使用 GitHub Pages 发布，部署源为 gh-pages 分支。main 分支保留网页源码、规则测试及产品方案。

素材覆盖说明：三句留言 × 三种视觉风格共有九张主场景；“霓虹现场＋飞去月球”另有漫游者和共鸣体两个独立人格场景。其余组合的人格目前体现在字号、对齐和人格标识，复用对应主场景。有限原型用这些实例表达设计方向，不宣称 27 种组合都有独立生图。
