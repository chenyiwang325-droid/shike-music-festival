# Third-party assets

qrcode-generator 1.4.4 by Kazuhiko Arase, MIT license. Original copyright and license header retained in dist/assets/qrcode.js. Source: https://github.com/kazuhikoarase/qrcode-generator

Poster scenes were generated with OpenAI's built-in image generation tool for this fictional white-peach sparkling-water campaign. Each scene uses the supplied fictional product identity as a visual reference; exact prompts are included in the submission records. No API is called at runtime.

Images are finite simulation examples, not representations of real attendees or an actual event. All image scenes are 1024×1536; the shared Canvas renderer exports 1080×1620 personalized mock posters.
